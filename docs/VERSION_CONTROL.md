# MCP Workbench 项目版本管理与一键回退指南

本项目内置了基于 Git 的**本地原子快照与安全回滚机制（Project Snapshot & Rollback Engine）**，确保您在自己写代码、修改配置或进行各种实验时，拥有随时可用的“全局撤销”与“时光机”。

---

## 1. 核心指令清单

在交互控制台（双击 `start-cli.bat` 或运行 `node ./micro_agent/cli_frontend.mjs`）中，您可以直接使用以下命令：

| 命令 | 作用 | 触发时机 | 示例 |
| :--- | :--- | :--- | :--- |
| **`undo`** | **一键撤销刚才的所有临时修改** | **您自己写代码改乱了，想一秒复原** | `undo` |
| **`rollback <目标>`** | **一键回退到指定历史版本或快照** | 想切回昨天的版本或最初的基线版 | `rollback v0.0.3-baseline` |
| **`history [条数]`** | 查看当前工作区状态及历史版本时间线 | 随时查看历史记录 | `history` 或 `history 10` |
| **`snapshot <名> [说明]`** | 主动为项目打一个有特定名字的标签 | 想要特别命名某个里程碑时 | `snapshot "stable-v1" "阶段成果"` |
| **`diff [目标版本]`** | 预览当前代码与指定快照的代码差异 | 回退前想确认改了什么 | `diff v0.0.3-baseline` |

---

## 2. 当您“自己修改代码”时，如何零心智负担使用？

### 场景 A：我自己改了一堆代码，改崩了想丢弃
- **您不需要提前打快照！**
- 直接在控制台敲一个单词：
  ```text
  undo
  ```
  或者在对话里直接告诉我：“帮我撤销刚才的改动”。
- 系统会自动将所有被修改的文件还原，删除新建的临时文件，**瞬间恢复到修改前干净的状态**。

### 场景 B：我想回退到很久以前的某一版
- 敲 `history` 看一眼历史列表。
- 选一个版本号（例如 `v0.0.3-baseline`）敲 `rollback`：
  ```text
  rollback v0.0.3-baseline
  ```

---

## 3. 双重安全防误损保障（Pre-Rollback & Pre-Undo Safety Backup）

无论是执行 `rollback` 还是 `undo`，系统都内置了**绝对不丢代码**的防呆设计：
- 在清空当前修改的**前一毫秒**，系统会自动把您刚才修改的内容悄悄打包为一个紧急备份标签（如 `backup_before_undo_<时间戳>`）。
- 就算您手滑敲错了 `undo`，想找回刚才改的代码，只要输入 `rollback <备份标签>`，刚才的代码又能瞬间找回！
